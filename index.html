CIMD demo

Static metadata host for Client ID Metadata Document demos against cidaas nightly.

Authorization code (PKCE)

Happy path: /client.json (token_endpoint_auth_method: none). Failure path: /invalid/client.json (client_id ≠ URL).

Client credentials (private_key_jwt)

Metadata: /cc/client.json + /cc/jwks.json. CIMD requires client authentication for this grant — demo uses a demo-only RSA key (not for production). Trust Desk ceilings must allow client_credentials and private_key_jwt.
